# Story Notes (이야기 노트)

SillyTavern 확장. 지나간 대화를 구간마다 짧은 노트로 정리해 두고, 그 노트를 AI에게 대신 보내서 긴 채팅에서도 흐름을 기억하게 합니다.

## 기능

- 메시지 N개마다 자동 정리, 또는 「지금 정리하기」 버튼으로 바로 정리
- 적을 항목 고르기: 줄거리, 장소, 날짜·시간, 관계, 감정, 새 인물, 남은 떡밥
- 정리가 끝난 메시지는 숨겨서 AI에게 안 보냄 (최근 N개는 남김)
- 노트 최대 분량(토큰) 안에서 최근 노트부터 AI에게 전달
- 넣을 자리: 대화 사이(깊이 지정) / 메인 프롬프트 뒤 / 맨 앞
- 「노트 보기」 창에서 노트 수정·삭제 (삭제하면 숨겼던 메시지가 다시 보임)
- 노트는 채팅마다 따로 저장
- 정리에 쓸 모델을 따로 고를 수 있음 (예: 채팅은 큰 모델, 정리는 빠른 flash 모델). 기본은 지금 채팅 모델
  - 목록은 지금 연결(채팅 완성 근원)을 따라감: AI Studio·Vertex·Custom 등. 모델 추가(Vertex Models+) 확장으로 넣은 모델도 나옴
  - 키·역방향 프록시(중계기)·Vertex 지역·Additional Parameters(Flex 등)는 지금 연결 설정을 그대로 씀
  - 구글 연결에서는 `gemini-3.8-flash`를 추천으로 맨 위에 보여 줌
  - 연결까지 바꾸고 싶으면 저장한 연결 프로필도 고를 수 있음

SillyTavern 1.19.0에서 확인했습니다. 1.2.0의 모델 선택은 1.19.1에서 확인했습니다.
