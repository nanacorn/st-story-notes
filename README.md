# Story Notes (이야기 노트)

SillyTavern 확장. 지나간 대화를 구간마다 짧은 노트로 정리해 두고, 그 노트를 AI에게 대신 보내서 긴 채팅에서도 흐름을 기억하게 합니다.

## 기능

- 메시지 N개마다 자동 정리, 또는 「지금 정리하기」 버튼으로 바로 정리
- 적을 항목 고르기: 줄거리, 장소, 날짜·시간, 관계, 감정, 새 인물, 남은 떡밥
- 정리가 끝난 메시지는 숨겨서 AI에게 안 보냄 (최근 N개는 남김)
- 노트 최대 분량(토큰) 안에서 최근 노트부터 AI에게 전달
- 넣을 자리: 대화 사이(깊이 지정) / 메인 프롬프트 뒤 / 맨 앞
- 「노트 보기」 창에서 노트 수정·삭제 (삭제하면 숨겼던 메시지가 다시 보임)
- 노트는 채팅마다 따로 저장
- 정리에는 지금 연결된 API를 그대로 사용

SillyTavern 1.19.0에서 확인했습니다.
